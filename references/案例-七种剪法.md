# 案例｜《AI 剪辑绝招大公开》

约 7 分 43 秒的横版，用自己的原声串起七条真实作品。以下为实际处理方式，可迁移到不同内容。

| 叙事任务 | 画面怎么做 |
| --- | --- |
| 在开场兑现七种方法 | 真实结论先进入，七条作品先平铺供观众认全。下一句改变讲述任务时，再引导逐个轮播，保持总览可见。 |
| 讲如何把模糊需求变成作品 | 让同一张需求纸拆成受众、材料、交付和验收，再让画面轨和配音轨组成视频。正式案例末尾收紧空耗，让口播顺接下来。「带劲」在原话重音压印；「剪腻」用重复出现的实际剪辑步骤交代原因。 |
| 讲本人音色怎样用于 MG | 从录音到克隆、回听、选题、稿件和配音依次推进。录音展开为 AI 克隆音色；从原稿和声轨指向实际「AI 配音 + MG 动效」成片，让同一案例窗放大连播。播完从末帧转到新的听感，避免无关色页闪回。 |
| 讲数字人再到随拍 | 照片与实际音轨合成后播原案例，讲限制时分别看口型和手势。与随拍相接时用手机翻转，真实人像入画。竖屏案例保持原比例，左侧用原片波形、播放进度补充信息。 |
| 讲录屏、杂志风和手绘 | 说到 OBS 放正式标志，贴近名称给一句「电脑画面和摄像头可以一起录」。用窗口移入原位演示如何合成。标注依次落在左侧操作、右上笔记和右下真人。画板用开口角标绕开画中讲解者。讲版式验证时，让原例腾出一侧，再显示原片里有依据的播放数字。 |
| 说明访谈如何剪 | 由访谈全景认出三个人，再让人物卡停稳。讲切镜时原先三人全景只有约 0.37 秒，后延至约 1.7 秒，再切两人问答和关键反应。印章用真实回答「太贵了」，避开原视频标题、字幕和人脸。该时长服务本句，其他镜头按内容确定。 |
| 演示复用与交付 | 主页用真实作品墙。知识库用实物截图和目录；「从夯到拉」直接展示熟悉的空榜，标明「国内 AI 产品与模型」和兴趣条件。用手绘画板原片代替旧例说明复用。只将封面改成用户选定的滨海暮色单场景海报，按生活照建立人像，以三种构图适配平台，复用已通过的成片。 |

原案例的伴奏参数作为这套风格的复现参考。过往案例作为方法参考，其他新任务使用当期的作品、口播与封面素材。
