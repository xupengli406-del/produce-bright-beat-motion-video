# 封面与交付

## 封面

- 片名用已确认的原文。副文先给真实观看收益，再用案例数量或方式补充。标题、人物、关键动作和道具之间留出清楚边界，一个缩略图有一个主阅读顺序。
- 使用本人明确提供或认可的生活照、商务照或当期拍摄素材做身份参考。看脸、头发、表情、头颈、肩线、手与工具接触是否自然。头和肩转换朝向要符合真实姿势。替换封面肖像时只操作封面。
- 先做与主题相关的无字场景，再融入身份参考，最后以可编辑文字排版。测量字形、描边、边距和主体避让，在原尺寸和手机缩略图均看实际导出。
- 美漫斜切可以用原创几格黑墨线分镜。用户指定「AI 产品怎么选？」式中央标题牌时，标题和副文整组放中间，画格在上下或两侧，分镜线绕开脸和完整道具。若选择粉橙暮色的单场景效果，用原创场景、光色和舒服的自然姿势，标题位置按构图确定。按当期选版决定风格，不把某一期选版当成默认。
- 完整四平台发布包用 3:4、4:3、16:9 三种比例分别构图。选过的比例以该图为准；横向扩展时保护选定的人像和片名层级，单独布局正文与主体。仅做封面候选时按请求比例出图。明确选定后让正式目录只出现该方向。

## 发布包

- 可共用同一成片时交一份最终 MP4。附三比例封面、同一时间线的中文、英文、中英双语 SRT、可粘贴章节、四平台分别写好的文案和简短材料映射。
- 抖音、小红书、视频号、B站各按阅读场景调整篇幅和标题。直接说观众可以看什么。个人体验、可能做的选题和已经完成的内容各自表述，保留口播的条件。
- 核对影片时长、章节开始点、使用说明链接和封面文件。替换封面时确认包与当前目录逐项相同，并验证已验收成片仍为同一文件。发布与发送按用户当次授权办理。
- 收录本 Skill 的视频案例时使用获授权的完整验收成片。飞书在案例正文放可播放的视频，GitHub 在案例说明和 README 放完整 MP4 入口，大文件用 Release 附件。截图、封面和节选可辅助讲解。核对读者可打开，视频时长、首尾和音轨符合验收版；上传原件时取回核对文件一致。
